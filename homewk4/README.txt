To view the README.md file in the parent folder, you may preview it with Typora (recommended), VS Code (with extension Markdown Preview Enhanced), or Github webpage.
If these hasn't been installed, you may open this website in your browser: https://www.typora.io/
Then, download the installation package according to your operation system, and run the .exe file to install Typora.
After installation, open the .md file with Typora.
