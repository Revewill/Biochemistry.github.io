To view the README.md file in the parent folder, you may open it with Visual Studio Code (VS Code) and click preview.
If VS Code hasn't been installed, you may open this website in your browser: https://code.visualstudio.com/
Then, download the installation package according to your operation system, and run the .exe file to install VS Code.
After installation, a shortcut key ctrl+O will allow you to browse for your file.
Choose the README.md file that you downloaded, and click preview.
For better experience, please install Markdown Preview Enhanced from the extension store.
